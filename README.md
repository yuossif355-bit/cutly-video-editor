# ✂️ Cutly — محرر فيديو من المتصفح

محرر فيديو عربي بشكل شبيه بـ CapCut، بيشتغل بالكامل في المتصفح. **مفيش تسجيل ومفيش رفع ملفات لأي سيرفر**: الفيديوهات بتفضل على جهازك.

## المميزات
- **تايم لاين متعدد المسارات:** نص، طبقة فيديو إضافية، المسار الرئيسي، وصوت
- **قص وتقسيم:** اسحب حواف المقطع، أو قسّمه عند المؤشر (`S`)، مع مغناطيس بيلزّق المقاطع في بعض
- **تحريك المقاطع بالسحب** بين المسارات، وتكرارها وحذفها
- **السرعة** من ×0.25 لـ ×4، ومستوى الصوت، وظهور واختفاء تدريجي
- **فلاتر وألوان:** سطوع، تباين، تشبع، تغبيش، أبيض وأسود، سيبيا، وإعدادات جاهزة
- **نصوص عربية** بخطوط (Cairo, Tajawal, Amiri, Lalezar, Reem Kufi) مع حدود وخلفية
- **تحريك وتكبير** أي عنصر مباشرة في المعاينة
- **أبعاد جاهزة:** 16:9 و 9:16 و 1:1 و 4:5
- **تراجع وإعادة** (حتى ١٠٠ خطوة) واختصارات كيبورد
- **تصدير** بصيغة WebM (أو MP4 لو المتصفح بيدعمها) بالصوت

## الاختصارات
| الاختصار | الوظيفة |
|---|---|
| `Space` | تشغيل / إيقاف |
| `S` | قسّم عند المؤشر |
| `Delete` | حذف المقطع المحدد |
| `Ctrl + D` | تكرار |
| `Ctrl + Z` / `Ctrl + Shift + Z` | تراجع / إعادة |
| `←` `→` | فريم بفريم (`Shift` = ثانية) |
| `Home` / `End` | البداية / النهاية |

## التشغيل
افتح `index.html` مباشرة (الأفضل عن طريق سيرفر محلي):

```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```

## النشر على GitHub Pages
**Settings ← Pages ← Deploy from a branch ← `main` / `(root)`**

## ملاحظات مهمة
- التصدير **في الوقت الحقيقي**: فيديو ٣٠ ثانية = ٣٠ ثانية تصدير، ولازم تسيب التبويب ظاهر قدامك.
- التصدير بـ `MediaRecorder` فبيخرج WebM في أغلب المتصفحات. للتحويل لـ MP4 استخدم أي محوّل أو ffmpeg.
- الأفضل Chrome أو Edge. بعض صيغ الفيديو (زي HEVC) ممكن متتفتحش حسب الكودكات المدعومة في المتصفح.
- المشروع **مبيتحفظش** بعد قفل الصفحة (الملفات روابط مؤقتة)، فصدّر شغلك قبل ما تقفل.

## بنية المشروع
```
index.html      الصفحة
style.css       التصميم
js/store.js     حالة المشروع: المسارات والمقاطع والتراجع (من غير DOM، بيتختبر في Node)
js/engine.js    الرسم على الكانفاس، التشغيل، الصوت، الاستيراد، التصدير
js/timeline.js  واجهة التايم لاين (سحب، قص، مؤشر، تكبير)
js/app.js       المكتبة، لوحة الخصائص، الأزرار، الاختصارات
tests/          اختبارات الوحدة + اختبار شامل في متصفح حقيقي
```
